GitHub 토큰으로 로그인

GitHub Personal Access Token을 입력하면 블로그에 직접 글을 발행할 수 있습니다.

  1. GitHub → Settings → Tokens에서 새 토큰 생성
  2. Note: nxt-blog-admin
  3. 권한: repo (전체 체크)
  4. 만료: 원하는 기간 설정
토큰은 브라우저 localStorage에만 저장됩니다.
